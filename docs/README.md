# Diagrams

Architecture and component diagrams are maintained as [Excalidraw](https://excalidraw.com/) files and rendered to PNG with [excalirender](https://github.com/JonRC/excalirender).

## Files

| Source | Output | Description |
|--------|--------|-------------|
| `build-component-diagram.mjs` | `component-diagram.excalidraw` / `.png` | EC2 Teleport Agent component diagram |
| `architecture-overview.excalidraw` | `architecture-overview.png` | High-level architecture overview |
| `mongodb-atlas-architecture.excalidraw` | `mongodb-atlas-architecture.png` | MongoDB Atlas integration |
| `architecture-components.excalidraw` | `architecture-components.png` | EC2 runtime components (from architecture.md wireframe) |

## Editing diagrams

### Programmatic (component diagram)

The component diagram is generated by a build script that embeds SVG icons from `docs/icons/`:

```sh
# Regenerate the .excalidraw file
node docs/build-component-diagram.mjs

# Render to PNG
bun run /path/to/excalirender/src/index.ts docs/component-diagram.excalidraw -o docs/component-diagram.png -s 2
```

Edit `docs/build-component-diagram.mjs` to change layout, add elements, or update icons.

### Manual (other diagrams)

Open any `.excalidraw` file directly at [excalidraw.com](https://excalidraw.com/) or in VS Code with the Excalidraw extension, then re-render:

```sh
excalirender docs/architecture-overview.excalidraw -o docs/architecture-overview.png -s 2
```

## Installing excalirender

excalirender uses [Bun](https://bun.sh/) and the [canvas](https://github.com/Automattic/node-canvas) native addon for rendering.

### macOS (Apple Silicon)

The compiled binary (`bun build --compile`) does **not** work on Apple Silicon — the `canvas.node` native addon fails to find its linked dylibs at runtime. Instead, run directly from source with `bun run`.

Install the native libraries that `canvas` links against:

```sh
brew install pkg-config cairo pango libpng jpeg giflib librsvg pixman
```

> **Note:** `jpeg` is keg-only (conflicts with `jpeg-turbo`) so it won't be symlinked into `/opt/homebrew` automatically. This is fine — `bun install` picks it up from the keg path.

Clone and install:

```sh
git clone https://github.com/JonRC/excalirender.git
cd excalirender
bun install
```

Run directly from source:

```sh
bun run /path/to/excalirender/src/index.ts <input.excalidraw> -o <output.png> -s 2
```

### Linux

```sh
sudo apt-get install -y build-essential libcairo2-dev libpango1.0-dev libjpeg-dev libgif-dev librsvg2-dev
```

Clone, `bun install`, and optionally compile a standalone binary:

```sh
git clone https://github.com/JonRC/excalirender.git
cd excalirender
bun install
bun build --compile ./src/index.ts --outfile excalirender
./excalirender -h
```
