# CHANGELOG

## 1.0.0

- Initial release
- Teleport v18 provider support
- EC2 ASG-based agent pool with IAM join method
- Dynamic configuration via confd + SSM Parameter Store
- SSH, Database, App, and Discovery service support
- DataDog Agent integration (journald logs + OpenMetrics)
- ElastiCache autodiscovery and managed IAM identity policies
- Configurable additional inline IAM policies
- Bootstrap commands for custom instance setup
